# Movie Ticket Booking System

## Project Overview
The Movie Ticket Booking System is a SQL-based database project designed to manage movies, theaters, screens, seats, customers, showtimes, bookings, payments, and reviews.

## Database Tables
This project contains 10 tables:
1. Theaters
2. Movies
3. Customers
4. Screens
5. Seats
6. Showtimes
7. Bookings
8. Booking Seats
9. Payments
10. Reviews

## SQL Concepts Covered
- DDL, DML, and DCL commands
- Primary keys, foreign keys, and constraints
- INSERT, UPDATE, and DELETE
- SELECT, DISTINCT, WHERE, ORDER BY
- Aggregate functions, GROUP BY, and HAVING
- INNER JOIN and LEFT JOIN
- Subqueries and correlated subqueries
- UNION and UNION ALL
- CASE statements
- Common Table Expressions (CTEs)
- Views and indexes
- Triggers, stored procedures, and functions
- Transactions and window functions
- LIMIT and OFFSET

## Tools Used
- MySQL 8.0
- Visual Studio Code
- Git and GitHub

## How to Run
1. Download or clone this repository.
2. Open MySQL Workbench.
3. Open `movie_ticket_booking_system.sql`.
4. Execute the SQL script.
5. Run the queries to explore the database.

## Project Purpose
This project demonstrates relational database design and practical SQL skills through a movie ticket booking scenario.
